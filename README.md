# Michael AI 👁️ v1.1-release
### Sovereign, Offline-First Multi-Agent Architecture & Telemetry Ecosystem

**Michael AI 1.1** is an advanced edge-computing intelligence and command platform covering vehicles, smart homes, and local infrastructure security.

## 🚀 Core Architecture
- **CorpusCallosumBridge**: Central orchestrator for tool registration, agent mapping, and robust intent routing.
- **IntentRouter**: Dynamic command matching to route natural language prompts to active hardware/software handlers.
- **Telemetry Vault**: Local SQLite (`michael_telemetry.db`) and `blackbox.log` integration ensuring offline data sovereignty.

## 🛠️ Tech Stack
- **Languages:** Python, C++
- **Environments:** Linux, Termux, Google Colab, GitHub Codespaces
- **AI / Computer Vision:** Multi-agent frameworks, YOLOv8, OpenCV, Gemini Live API integrations
- **Telemetry & Protocols:** SocketCAN, ISO-TP, Automotive CAN bus telemetry
