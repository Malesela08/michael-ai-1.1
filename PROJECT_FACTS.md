# Guiding Angel Project Facts

* **Project Name**: Aegis-Kopano Digital Brain.
* **Core Technology**: Sovereign, offline-first AI systems utilizing Ollama, Termux, and Python.
* **Primary Application**: Revolutionary security system with real-time threat detection and vehicle immobilization.
* **Current Infrastructure**: Integration of Edge AI hardware modules and a library plane bridge.
* **Operational Security**: The system triggers live video monitoring and automated SMS alerts to law enforcement.
* **Strategic Foundation**: Development of a 10-bay technical workshop and a dedicated youth learnership program.
* **Regulatory Status**: Provisional patent application (Form P1) filed with the CIPC.
